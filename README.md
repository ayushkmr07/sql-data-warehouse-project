
# SQL Data Warehouse Project

##  Description

This project focuses on building a modern **SQL Data Warehouse** to integrate data from multiple source systems, including **CRM** and **ERP**.

The data follows a **Bronze, Silver, and Gold architecture**. Raw data is first stored in the Bronze layer, then cleaned and standardized in the Silver layer. Finally, business-ready data is created in the Gold layer for analytics and reporting.

The project demonstrates important **Data Engineering** concepts such as data integration, ETL processing, data cleaning, transformation, and data modeling.

##  Project Objective

* Build a modern SQL-based Data Warehouse.
* Integrate data from multiple source systems.
* Clean and standardize raw data.
* Implement Bronze, Silver, and Gold layers.
* Transform raw data into business-ready datasets.
* Develop analytics for better business insights.

## ⚙️ Project Requirements

* SQL Server
* SQL Server Management Studio (SSMS)
* CRM source data
* ERP source data
* Basic SQL knowledge
* Understanding of ETL and Data Warehousing concepts

##  Project Specifications

###  Bronze Layer

Stores raw data from source systems without applying transformations.

* **Object Type:** Tables
* **Data:** Raw data
* **Load:** Batch Processing / Full Load / Truncate & Insert
* **Transformations:** None

###  Silver Layer

Cleans and standardizes the raw data.

* **Object Type:** Tables
* **Data Cleansing**
* **Data Standardization**
* **Data Normalization**
* **Derived Columns**
* **Data Enrichment**

###  Gold Layer

Creates business-ready data optimized for analytics and reporting.

* **Object Type:** Views
* **Data Integration**
* **Aggregations**
* **Business Logic**
* **Star Schema**
* **Fact and Dimension Tables**

## 📊 Analytics and Reporting
